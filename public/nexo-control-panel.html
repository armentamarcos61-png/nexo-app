Inicia sesión como desarrollador

Este panel es independiente de Nexo. Puedes entrar con tu contraseña de Nexo o verificar el correo. El servidor comprueba que seas administrador.

Nexo guarda las contraseñas de registro en este navegador, pero este panel usa una cuenta verificada de Supabase. «Vincular mi contraseña de Nexo» comprueba tu clave local y después solicita verificar el correo para que puedas utilizar la misma contraseña en ambos sistemas.

Actualmente Supabase está enviando un enlace, no un código de seis dígitos. Si al tocarlo aparece localhost:3000, no abras esa dirección: copia el enlace original del correo y pégalo arriba. Nunca compartas tu contraseña ni el enlace.

¿Cómo activar el código de seis dígitos?

La configuración del correo se realiza en Supabase, no desde el navegador de Nexo.

1. En URL Configuration, cambia el Site URL y agrega la ruta del panel como Redirect URL: https://armentamarcos61-png.github.io/nexo-app/nexo-control-panel.html.

2. En Email Templates → Magic Link, cambia el mensaje para mostrar {{ .Token }}. Supabase enviará un código en lugar de un enlace.

Si Supabase solicita SMTP personalizado para modificar el correo, primero hay que verificar un dominio de envío. Mientras tanto, entra con tu contraseña.
